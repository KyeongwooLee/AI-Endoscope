QUESTION: The size of a bathroom is 96 sq ft. If the width of the bathroom is 8 feet and the owner wants to extend it by 2 feet on each side, what is the new area of the bathroom?
SOLUTION: Step 1: Calculate the original length of the bathroom.
The area of a rectangle is given by the formula: Area = Length × Width.
Given the area is 96 sq ft and the width is 8 ft, we can find the length by rearranging the formula:
Length = Area ÷ Width
Length = 96 ÷ 8
Length = 12 ft

Step 2: Determine the new dimensions after extending by 2 feet on each side.
The original width is 8 ft, and the owner wants to extend it by 2 ft on each side. Therefore, the new width will be:
New Width = Original Width + 2 × Extension
New Width = 8 + 2 × 2
New Width = 8 + 4
New Width = 12 ft

Step 3: Calculate the new area of the bathroom.
The new length is 12 ft, and the new width is 12 ft. Using the area formula again:
New Area = New Length × New Width
New Area = 12 × 12
New Area = 144 sq ft
