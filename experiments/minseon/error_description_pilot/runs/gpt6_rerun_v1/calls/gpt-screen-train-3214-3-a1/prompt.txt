QUESTION: Carla had 400 chickens on her chicken farm. However, 40% of the chicken died due to a certain disease. How many chickens were there if she bought ten times as many chickens as the number that died due to disease?
SOLUTION: Step 1: Calculate the number of chickens that died.
- Total chickens = 400
- Percentage that died = 40%

Number of chickens that died = 40% of 400
Number of chickens that died = 0.40 * 400
Number of chickens that died = 160

Step 2: Determine the number of chickens Carla bought.
- Number of chickens that died = 160
- Carla bought ten times as many chickens as the number that died.

Number of chickens Carla bought = 160 * 10
Number of chickens Carla bought = 1600

Step 3: Calculate the total number of chickens after the purchase.
- Number of chickens that died = 160
- Number of chickens bought = 1600

Total number of chickens = Number of chickens that died + Number of chickens bought
Total number of chickens = 160 + 1600
Total number of chickens = 1760
