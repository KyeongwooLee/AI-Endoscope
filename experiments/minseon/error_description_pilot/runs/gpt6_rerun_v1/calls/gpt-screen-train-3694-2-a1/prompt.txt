QUESTION: For many years, the number of sharks in Pelican Bay has been twice the number of Pelicans in Shark Bite Cove.   But today scientists say one-third of the Pelicans in Shark Bite Cove have moved to Pelican Bay.  If there are still 60 sharks in Pelican Bay,  how many Pelicans remain in Shark Bite Cove?
SOLUTION: Step 1: Let's denote the number of Pelicans in Shark Bite Cove as \( P \).
Step 2: According to the problem, the number of sharks in Pelican Bay is twice the number of Pelicans in Shark Bite Cove, so the number of sharks in Pelican Bay is \( 2P \).
Step 3: Today, one-third of the Pelicans in Shark Bite Cove have moved to Pelican Bay. Therefore, the number of Pelicans that moved is \( \frac{1}{3}P \).
Step 4: The number of Pelicans that remain in Shark Bite Cove is \( P - \frac{1}{3}P = \frac{2}{3}P \).
Step 5: The number of sharks in Pelican Bay remains 60. Since the number of sharks is twice the number of Pelicans in Shark Bite Cove, we have \( 2 \times \frac{2}{3}P = 60 \).
Step 6: Solving for \( P \), we get \( \frac{4}{3}P = 60 \), so \( P = 60 \times \frac{3}{4} = 45 \).
Step 7: The number of Pelicans that remain in Shark Bite Cove is \( \frac{2}{3}P = \frac{2}{3} \times 45 = 30 \).

#### 30
The number of Pelicans remaining in Shark Bite Cove is 30.
