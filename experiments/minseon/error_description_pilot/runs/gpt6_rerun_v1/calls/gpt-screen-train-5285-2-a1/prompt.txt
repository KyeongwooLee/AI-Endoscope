QUESTION: The number of trees is three times more than the number of stones in the courtyard. There are also twice as many birds in the trees as the combined number of trees and stones in the yard. If the number of stones is 40, how many birds are in the trees?
SOLUTION: Step 1: Determine the number of stones.
Given: Number of stones = 40

Step 2: Calculate the number of trees.
Number of trees = 3 times the number of stones
Number of trees = 3 * 40
Number of trees = 120

Step 3: Calculate the combined number of trees and stones.
Combined number = Number of trees + Number of stones
Combined number = 120 + 40
Combined number = 160

Step 4: Calculate the number of birds in the trees.
Number of birds = Twice the combined number of trees and stones
Number of birds = 2 * 160
Number of birds = 320

#### 320
The number of birds in the trees is 320.
