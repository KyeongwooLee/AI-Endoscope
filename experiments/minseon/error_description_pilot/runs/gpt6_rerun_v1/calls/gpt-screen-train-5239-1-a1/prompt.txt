SOLUTION: To find the length of time between eating each peanut, we need to divide the total flight time by the number of peanuts.

Total flight time = 2 hours = 120 minutes
Number of peanuts = 4

Length of time between eating each peanut = Total flight time / Number of peanuts

#### 30
This is the length of time, in minutes, between eating each peanut.
