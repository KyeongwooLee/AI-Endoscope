# Data Attribution

These packages contain upstream question/reference text, Qwen-generated
responses, automatically derived numerical correctness labels, model features,
and saved verifier results/checkpoints. Numerical agreement is not human
validation of the complete reasoning or of the reference answer.

## Generation and related annotations

Response model: https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct
Model revision: 989aa7980e4cf806f80c7fef2b1adb7bc71aa306
No model weights are distributed. Generated responses can be incorrect.
Error-type annotations are distributed separately in the
error-taxonomy-full-v1-draft release, not included in these data packages.
Those related annotations were authored directly by the assistant in the
project conversation, not by human annotators or an independently validated
judge, and remain NOT REVIEWED by humans. Response IDs/hashes link the releases.
